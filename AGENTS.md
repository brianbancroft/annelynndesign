# AGENTS.md

This is a design portfolio homepage. Keep JavaScript to a minimum and lean on HTML and CSS wherever possible, while still making the site look polished and aesthetically pleasing. Only add JS when there's no reasonable CSS/HTML alternative.

The goal of the site is to act as a traffic funnel to the **contact page**. Every page and design decision should guide visitors toward getting in touch.
